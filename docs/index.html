Features

为「免费 + 实时」做的每个决定

🔇

完全离线 ASR

SenseVoice int8 端侧推理（sherpa-onnx ONNX Runtime），0 元、0 流量、0 等待，五语自动判别。

实时双语字幕

Why not

为什么不选它们

Vosk

纯离线可用，但中文/韩文识别质量与标点/ITN 明显弱于 SenseVoice，且无多语自动判别。

whisper.cpp / whisper-streaming

质量好但中端手机 RTF>1 实时性不够，流式方案复杂。

sherpa-onnx 内置流式 zipformer

仅 zh-en 双语，体积更大，无日韩。
